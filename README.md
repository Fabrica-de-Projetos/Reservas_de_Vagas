# SpotLivre
## Sobre o projeto
  O objetivo do projeto é ser um HUB de estacionamentos, onde o proprietário pode cadastrar o seu estabelecimento e os usuarios podem fazer uma reserva antecipadamente. O sistema mostrara vagas e horarios disponiveis,         auxiliando a organização do usuario, que saberá onde e quando, exatamente poderá estacionar, e também para o dono de um estacionamento, que poderá expandir a visibilidade do seu negócio.
