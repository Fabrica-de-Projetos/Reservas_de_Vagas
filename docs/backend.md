# Padrão Arquitetural do Backend
    Arquitetura: MVC

    Motivo: Desenvolvedores que participarão ativamente na construção do backend já possuem experiência prévia com essa arquitetura em projetos passados (tanto em PHP quanto em C# (davi)) assim solucionando a questão de trabalharmos com tecnologias e conceitos que já temos domínio e facilitando o desenvolvimento


# Forma de comunicação com o Frontend
    Forma de comunicação com Frontend: API REST

    Motivo: Experiência prévia dos devs que participarão do desenvolvimento e por ser o modelo de comunicação front-back mais utilizado no mercado, facilitando processos de crud etc (exemplo de api rest: GET, POST, DELETE E PUT), também será utilizado a passagem de informações via JSON, utilizando a ferramente POSTMAN para testes.
